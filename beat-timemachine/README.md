# 비트 타임머신 (BEAT TIME MACHINE)

중2 음악 「시대의 역사적 흐름과 문화적 동향을 담은 음악」 프로젝트용 레트로 아케이드 게임.
음악 요소의 정의를 고르는 퀴즈 대신, **음악 요소가 곧 조작법**이 되도록 만들었습니다.

| 음악 요소 | 게임 속에서 |
|---|---|
| 가락(음높이) | ↑↓로 오선 위를 날며 음표 막대를 잡으면 그 음이 울림 (높이 = 음높이, 길이 = 음 길이) |
| 셈여림 | SPACE를 누르는 힘(게이지) = 소리 크기. f 막대는 꾹, p 막대는 떼기 |
| 빠르기 | 곡의 템포가 곧 화면 스크롤 속도. 빠르기말이 실시간 표시 |
| 박·박자 | 마디선·박 선과 메트로놈, 변박 스테이지 |
| 음색 | 시대마다 다른 합성 악기 (쳄발로 → 피아노포르테 → 오케스트라 → 불협화음 → 신시사이저) |

## 스테이지
1. 바로크 – 미뉴에트 G장조: 계단식 셈여림, 일정한 박
2. 고전주의 – 하이든 「놀람」 주제: 질문-대답 악구, 갑작스러운 ff
3. 낭만주의 – 그리그 〈산왕의 궁전에서〉: accel. + cresc.
4. 20세기 – 스트라빈스키 풍 변박(창작): 변박, 불규칙 악센트, 불협화음
5. 지금 – K-팝 스타일 훅(창작): 싱코페이션, 훅 반복

스테이지가 끝나면 「방금 손이 한 것 = 음악 요소」 정리와 시대 공감 문장 쓰기(복사해서 공유문서에 붙이기)가 나옵니다.

`index.html` 하나로 동작합니다(소리는 Web Audio로 직접 합성, 외부 음원 없음).

# 내가 먹는 게 나

0시부터 0시까지 내가 먹은 음식 사진을 찍으면, 그릇은 빼고 **음식만** 오려서 그날의 "나" 모양 틀 안에 콜라주로 쏙쏙 채워 넣는 앱.
하루가 지나면 그날의 나는 피규어처럼 **달력 수납장**에 한 칸씩 모입니다.

## 기능
- **오늘의 나**: 📷 먹은 거 찍기 / 🖼️ 앨범에서 → 음식만 오려내기 → 몸 틀에 콜라주로 자동 배치
- **오려내기 도구**
  - ✨ 자동: 사진 가장자리부터 식탁·하얀 그릇 같은 밋밋한 영역을 지워서 음식만 남김
  - ⭕ 동그라미: 그릇 안쪽만 동그랗게 (끌어서 옮기고 크기 조절)
  - ✍️ 손으로: 손가락으로 음식 둘레를 그려서 오리기
  - 🖼️ 통째로
- **얼굴 넣기**: 내 사진을 동그라미에 맞춰서 머리에 넣기 (안 넣으면 그려진 기본 얼굴)
- **나 수납장**: 월별 달력 모양 나무 수납장, 날짜 칸마다 그날의 나 피규어 / 눌러서 크게 보기
- 💾 그림 저장 (PNG)
- 자정이 지나면 자동으로 새 하루 시작
- 모든 사진은 폰 안(IndexedDB)에만 저장, 서버 없음
- 폰트: 어린이 손글씨 느낌의 Gamja Flower (+ Gaegu)

## 실행
정적 파일이라 아무 웹서버로나 열면 됩니다.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages 등에 올린 뒤 폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.
(카메라·파일 접근을 위해 https 또는 localhost에서 열어야 합니다.)

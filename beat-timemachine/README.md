# 비트 타임머신 (BEAT TIME MACHINE)

중2 음악 「시대의 역사적 흐름과 문화적 동향을 담은 음악」 프로젝트용 레트로 아케이드 게임.
음악 요소의 정의를 고르는 퀴즈 대신, **음악 요소가 곧 조작법**이 되도록 만들었습니다.

| 음악 요소 | 게임 속에서 |
|---|---|
| 가락(음높이) | ↑↓로 오선 위를 날며 음표 막대를 잡으면 그 음이 울림 (높이 = 음높이, 길이 = 음 길이) |
| 셈여림 | SPACE를 누르는 힘(게이지) = 소리 크기. f 막대는 꾹, p 막대는 떼기 |
| 빠르기 | 곡의 템포가 곧 화면 스크롤 속도. 빠르기말이 실시간 표시 |
| 박·박자 | 마디선·박 선과 메트로놈, 변박 스테이지 |
| 음색 | 시대마다 다른 합성 악기 (쳄발로 → 피아노포르테 → 오케스트라 → 불협화음 → 신시사이저) |

## 스테이지
1. 바로크 – 미뉴에트 G장조: 계단식 셈여림, 일정한 박
2. 고전주의 – 하이든 「놀람」 주제: 질문-대답 악구, 갑작스러운 ff
3. 낭만주의 – 그리그 〈산왕의 궁전에서〉: accel. + cresc.
4. 20세기 – 스트라빈스키 풍 변박(창작): 변박, 불규칙 악센트, 불협화음
5. 지금 – K-팝 스타일 훅(창작): 싱코페이션, 훅 반복

## 학생 기록 모으기 (구글 시트)

학생은 처음에 **학번 · 닉네임 · 학급코드**를 입력합니다. 스테이지가 끝날 때마다 기록이, 「문장 제출」을 누르면 감상 문장이 선생님 구글 시트로 갑니다.

- 학번과 학급코드가 **학급코드표와 일치** → `3학년 1반` ~ `3학년 9반` 시트
- 일치하지 않거나 코드를 비운 경우 → `그외` 시트 (비고 칸에 「학번·학급코드 불일치」)
- 학급코드는 학번 30100 ~ 30928 (1~9반, 00~28번, 261명)에게 하나씩 4글자로 부여됩니다.
  코드는 **선생님 시트 안에만** 있고 게임 코드(공개 저장소)에는 들어 있지 않습니다.

### 선생님 설정 (한 번만, 5분)
1. 구글 드라이브에서 **새 구글 스프레드시트**를 만듭니다. (이름 예: 비트 타임머신 기록)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여 넣고 저장합니다.
4. 위쪽 함수 목록에서 **`setup`** 을 고르고 **▶ 실행** → 권한 허용
   (「확인되지 않은 앱」 경고가 나오면 고급 → 이동을 누르세요. 선생님 본인이 만든 스크립트라서 나오는 경고입니다.)
   → 시트에 `학급코드표`, `3학년 1반`~`9반`, `그외` 탭이 생깁니다.
5. 오른쪽 위 **배포 → 새 배포 → 톱니바퀴에서 「웹 앱」** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   → 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 이 저장소의 [`config.js`](config.js)에 그 URL을 넣고 커밋합니다.
   ```js
   window.BTM_RECORD_URL = 'https://script.google.com/macros/s/…/exec';
   ```
7. `학급코드표` 탭을 반별로 인쇄하거나 잘라서 학생에게 나눠 줍니다.

> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로입니다.

### 시트에 쌓이는 항목
기록ID · 저장 시각 · 학번 · 닉네임 · 스테이지 · 시대 · 결과(클리어/게임오버) · 랭크 · 점수 · 가락 잡기(%) · 셈여림 정확도(%) · PERFECT · 최대 콤보 · 연습 모드 · 감상 문장 · 비고
